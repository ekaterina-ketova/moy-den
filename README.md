# Мой день · Екатерина Кетова

Личный дневник практик, состояния и рефлексии.

Разделы: Протокол, Состояние, Рефлексия (включая Учиться · Проявленность · Продажа и благодарности), Аскезы (разборы СВО), Разборы недели, Аналитика.

Основа интерфейса: https://github.com/irinavedipro/pitta-checklist. Оригинальный проект не изменяется.

Записи сохраняются в браузере на этом устройстве. Для переноса прежних записей используйте резервную копию JSON и кнопку восстановления. Новый адрес сайта имеет отдельное браузерное хранилище.

Публикация: Settings → Pages → Deploy from a branch → main → / (root) → Save.
